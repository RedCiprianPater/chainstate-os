# CHAINSTATE OS

Reference repository scaffold for a local-first cognitive Linux OS.

- `hf-space/index.html`: single-file black/white HF Space landing page and simulated live demo.
- `installer/install-chainstate.sh`: fail-closed installer authorization gate.
- `docs/PAYMENT_PROTOCOL.md`: payment and same-wallet signature protocol.
- `docs/ARCHITECTURE.md`: trust planes and safety boundaries.
- `docs/RUNBOOK.md`: deployment checklist.
