# Architecture Summary

Eight trust planes: Interface, Skill, Cognitive, Metacognitive, Constitutional, Execution, Continuity, and Hardware.

Core invariants: perception is not intent; intent is not authorization; authorization is not execution; representation is not authority; local sovereignty; reversibility; provenance; fail closed; degraded continuity; falsifiability; independent kill-gate seat; metacognitive isolation.

The cognitive plane produces proposals only. The metacognitive and kill-gate services challenge claims independently. The constitutional plane applies hard vetoes and consent. Execution is capability-scoped and sandboxed. Physical actuation is default-deny and requires a separately reviewed safety case with interlocks, authenticated operators, rate limits, and safe failure behavior.
